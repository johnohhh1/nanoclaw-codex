# Phases

## Phase 1

Create structured run events and persist them.

Deliver:
- trace id
- event log
- command events
- container lifecycle events
- message in/out events

## Phase 2

Expose a live operator page in the existing Web UI.

Deliver:
- active runs list
- live timeline
- terminal stream
- metadata panel

## Phase 3

Add source-control and file observability.

Deliver:
- current git diff
- changed file list
- file activity events

## Phase 4

Add browser observability.

Deliver:
- browser action events
- screenshots
- Playwright and agent-browser artifacts

## Phase 5

Add replay/history and deeper operator controls.

Deliver:
- run history
- replay timeline
- stop/interrupt controls
- artifact browser
