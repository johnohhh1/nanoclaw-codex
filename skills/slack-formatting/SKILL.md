# slack-formatting

Apply this skill when responding in a Slack-backed group.

## Rules

- Use `*bold*`, not `**bold**`.
- Use `<https://example.com|label>` for named links.
- Prefer bullet lists over numbered Markdown lists.
- Avoid Markdown tables and ATX headings.
- Keep messages compact and readable in chat.
